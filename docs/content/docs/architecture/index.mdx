# 架构与技术原理

影策由浏览器创作工作台、Go 业务后端、Node Pi Agent 执行层及持久化基础设施组成。画布编辑、模型生成、Agent 推理和短剧制作是互相协作的流程，但各自拥有不同状态、授权和完成条件。

本组文档基于实际源码和配置阅读，解释当前实现；不将设计提案、工作约定或测试文件的存在等同于已经实现并通过验收。没有新增产品功能或修改业务代码。

## 4. 五条核心技术链

### 用户操作与状态同步

`页面事件 → 局部状态/共享 Store → 本地持久化与远端同步 → API → 业务归属检查 → 数据库`。

高频拖拽坐标、稳定画布快照、React Query 查询结果不是同一种数据。账号切换需要等待旧 scope 的生成消费者、缓存写入和同步停止，再恢复新 scope；仅换一个 userId 不足以隔离异步写入。具体见前端专题。

### 模型生成与交付

`生成意图 → CreateTask → 配额/渠道/费用准入 → Task 持久化 → Worker 领取租约 → Provider → 上游 → 资源回存 → 终态及结果登记 → 前端回读/物化`。

任务记录是持久控制面；Redis 槽位解决并发协调。模型返回成功、对象保存成功、Task 终态、画布可见和费用结算分别有自己的失败窗口，不能合并成一个布尔值。媒体保存失败应沿恢复检查点重试保存，不能默认为重新生成。

### Agent 推理与批准

`用户消息 → Go run → Pi session → /model → Go 模型桥 → /tool → Go 策略`。

工具需要审批时，Go 记录待审批，Node 收到 pause 后结束本轮。批准后 Go 执行已批准操作；媒体后台等待结束后携带回执恢复 Pi。拒绝直接终结，不把拒绝当工具失败继续请求模型。已执行外部操作不能靠重启进程获得“恰好一次”保证。

### 短剧制作

`原文 → 作品设定与分集 → 镜头脚本 → 剧情段提示词 → 用户放行 → 段视频 → 时间线成片`。

DramaJob 描述业务步骤，Task 描述一次可调度执行，DramaSegment 是视频生成单位。模型输出须解析为领域对象；业务调度器从数据库状态推导下一步，不依赖浏览器一直开着。详见短剧专题。

### 资源身份与分发

`Resource 身份 → 当前存储位置/变体 → 用户或场景授权 → 临时访问描述 → 浏览器或上游取用`。

长期引用保存资源 ID；临时签名 URL 不应充当稳定身份。数据库备份不含全部媒体对象；缓存命中也不能代替授权。删除 Outbox 提交只表示清理已排队，不证明物理文件已经消失。

## 5. 数据所有权与一致性

| 数据 | 权威来源 | 其他副本/投影 | 关键注意点 |
| --- | --- | --- | --- |
| 账号与权限 | 服务端身份及业务归属 | 前端会话和功能隐藏 | 前端守卫不是授权结论 |
| 画布编辑 | 本地工作状态与已确认服务端版本 | scoped localforage、实时 presence | 未确认保存、冲突、临时光标分开处理 |
| 生成任务 | 数据库 Task/Result、租约和执行诊断 | 查询缓存、SSE 文本增量 | SSE 结束或浏览器 abort 不等于任务取消 |
| 模型产物 | Resource 状态和实际对象 | CDN、播放副本、浏览器缓存 | 上游成功与平台回存分开 |
| Agent | run、审批、事件、Pi JSONL 与 checkpoint | UI 消息与模型上下文 | JSONL 与语义摘要不是同一个状态载体 |
| 短剧 | Production/Episode/Segment/Job | 制作台、精修画布、渲染计划 | 同步任务结果后再决定派发 |
| 费用 | 预留、订单、核对记录 | 报价和 UI 显示 | 不确定提交不能一律退款或自动重发 |

## 6. 已发现的约定与实现差异

这些是文档核验发现，不是本次修复或变更授权。详细证据在各专题中。

| 容易误读的说法 | 当前实现 |
| --- | --- |
| Redis 是持久任务队列 | Task 表与租约驱动调度；Redis 做协调，也承载部分实时分发 |
| 后端 service 层另有业务实现 | service 主要是 app 的稳定别名导入面 |
| 任何资源有引用都不能删除 | 普通删除保护引用；purge/归档路径有不同规则，物理删除走 Outbox |
| 所有失败原样保留 AppError | `POST /tasks` 仍有 `fail(400, err)` 调用点 |
| 所有出站仅能精确放行私网 | 普通出站仍读取遗留全局开关；自定义渠道更严格 |
| 编辑器已拆成八个独立插件 | 当前 `editor-shell` 单插件提供八个插槽；旧时间线还有浏览器导出路径 |
| 文档站可独立构建 | 当前缺少 docs 的 package 和配置，不能执行旧说明中的构建命令 |
