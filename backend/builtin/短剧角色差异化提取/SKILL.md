## 目标

图片模型只能按文字画脸。同一画风下，“清隽”“凌厉”“冷硬”这类空词会让所有角色画成同一张脸。你写的每个单人角色的 appearance，必须让两个人放在一起能一眼分开。

## 写法：先脸，后衣

appearance 的顺序固定：

1. 性别、具体年龄（如“男，约24岁”，不用“青年”“中年”）。
2. 面部结构，每项都写具体形状，不写气质词：
   - 脸型与下颌：窄长脸尖下颌 / 方脸宽下颌 / 圆脸 / 鹅蛋脸 / 菱形脸 / 颧骨高
   - 眉：剑眉粗黑 / 细柳眉 / 短淡眉 / 断眉 / 八字眉
   - 眼：单眼皮细长 / 双眼皮圆眼 / 下垂眼 / 吊梢眼 / 深眼窝 / 眼距宽或窄
   - 鼻：高窄直鼻 / 宽鼻翼 / 鹰钩鼻 / 塌鼻梁 / 鼻头圆
   - 唇：薄唇 / 厚唇 / 唇角下垂 / 唇线分明
   - 记号：胡须样式、法令纹、皱纹、疤痕、痣、晒痕、缺牙，至少给重要角色一个
3. 发型与发色，体型，服装与随身物件。共 80-140 字。

原文写明的面部特征（如“左眉有疤”“络腮胡”）必须原样保留，其余按下面的矩阵补全。

## 差异矩阵

补全时按身份、年龄、阵营选倾向，不要所有人都取同一档：

| 维度 | 倾向 |
| --- | --- |
| 武人、护卫、杀手 | 方脸或宽下颌，眉骨高，鼻梁有断痕或疤，肤色深，粗糙 |
| 文臣、谋士、读书人 | 窄长脸或鹅蛋脸，眉形清细，眼细长，肤色偏白，少记号 |
| 底层、杂役、农人 | 颧骨高，肤色晒深，手脸有劳作痕迹，牙或皮肤有瑕疵 |
| 权贵、门阀 | 骨相饱满，眼神压迫，保养得当，皱纹少但法令纹深 |
| 反派 | 不靠“刻薄”二字，靠具体形状：薄唇下垂、吊梢眼、眼袋、鹰钩鼻 |
| 少年到青年 | 轮廓偏圆，皮肤紧，记号少 |
| 中年 | 法令纹、眼袋、下颌线松，须发开始杂色 |
| 老年 | 皱纹走向、斑点、稀疏或花白的须发、深陷的眼窝 |

## 区分规则

- 同性别、年龄相近的角色，脸型、眉、眼、鼻、唇五项里至少 3 项不同。
- 主角之间的差距要比配角之间更大。
- 不要用“俊朗”“清秀”“英气”这种词代替具体形状。
- 不要给不同角色复用同一个形容词组合。

## 自检

写完后把所有单人角色两两对比：如果两人只靠服装能分开，就改脸；如果有人没有任何面部记号和形状描述，补上。

## 群体角色

“几名……”“列于四壁的护卫”这类群体，参考图只画一名代表成员：保留群体说明（人数、服饰、装备），再按上面的面部公式给这名代表写脸，且与所有单人角色明显不同。

## 输出

输出结构、字段名以所在步骤要求的 JSON 为准，本技能只决定 appearance 怎么写。
